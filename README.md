# Custom Movie App 🎬

A lightweight, frontend-only movie app that fetches and displays the latest “Now Playing” movies using the **TMDb API**. Built with HTML, CSS, and vanilla JavaScript — ideal for learning API integration or as a simple web project.

## Features

- Shows current movies in theaters  
- Displays movie posters and titles in a clean, responsive grid  
- No backend needed — purely HTML/JS + TMDb API  
- Easy to host on platforms like **Netlify**  
- Fully customizable — you can easily add search, detail pages, and more

## Tech Stack

- Vanilla **JavaScript**  
- **HTML** & **CSS**  
- **TMDb API** for movie data  
- Hosted on (or deployable to) **Netlify**, GitHub Pages, or similar
